# 🎤 Automatic Speech Recognition (ASR) Tool

## 📌 Project Description

This project implements a simple **Automatic Speech Recognition (ASR) Tool** using Python.

The application captures speech through a microphone and converts the spoken words into text using a speech recognition service.

## 🎯 Objective

The main objective of this project is to understand and implement the basic working of an **Automatic Speech Recognition system**.

## ✨ Features

* 🎤 Captures voice through a microphone
* 📝 Converts speech into text
* 🖥️ Simple graphical user interface
* 🔄 Allows repeated speech recognition
* ⚡ Easy to use and test

## 🛠️ Technologies Used

* **Python**
* **SpeechRecognition**
* **PyAudio**
* **Tkinter**
* **Google Speech Recognition API**

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/sreedharshiha/implement-an-ASR-Automatic-Speech-Recognition.git
```

### 2. Open the Project Folder

```bash
cd implement-an-ASR-Automatic-Speech-Recognition
```

### 3. Install Required Libraries

```bash
pip install -r requirements.txt
```

## ▶️ How to Run

Run the following command:

```bash
python asr_tool.py
```

A window will open with the **Start Speaking** button.

### Steps

1. Click **Start Speaking**.
2. Speak clearly into the microphone.
3. The application records your speech.
4. The speech is converted into text.
5. The recognized text is displayed on the screen.
